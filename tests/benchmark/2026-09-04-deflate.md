# Deflate Integration Measurements

Measured 2026-09-04 EDT on an AMD Ryzen Threadripper 3990X, Linux x86_64,
Zig 0.16.0, ReleaseFast. Hyperfine used 3 warmups and 12 measured runs per
command. Both CPU and wall times, individual samples, and all follow-up controls
are retained in [the JSON log](2026-09-04-deflate.json).

Baseline source: `e28c2290316f61738686a7e800d7bf266ef32cd2`. The new decoder
is the implementation committed with this report. No existing Deflate path
could complete verification before this change, so Deflate has an initial
measurement rather than a before/after speedup claim.

## Existing LZMA2 Path

Times cover each batch, including process startup and one archive read.
Verification itself runs in memory for the stated iteration count.

| Corpus | Iterations | Before wall | After wall | Before CPU | After CPU |
| --- | ---: | ---: | ---: | ---: | ---: |
| Repeated text and x86 instructions, 360 KiB | 100 | 172.08 ms | 171.99 ms | 170.93 ms | 170.85 ms |
| Uniform random, 1 MiB | 50 | 108.98 ms | 108.63 ms | 108.12 ms | 107.77 ms |
| Gaussian bytes, 1 MiB, initial unpinned run | 50 | 3664.03 ms | 3935.16 ms | 3639.50 ms | 3892.67 ms |
| Gaussian bytes, CPU 24, both Nix builds | 10 | 731.83 ms | 741.34 ms | 726.32 ms | 736.02 ms |

CPU is hyperfine user plus system time. The initial Gaussian result was 7.4%
slower with large outliers. An after/before/before/after control on CPU 24
measured 732.94 ms before versus 757.41 ms after (3.3% slower, averaged across
the two groups for each binary). This comparison used a Nix-built baseline and
the local ReleaseFast binary rebuilt by the CLI test runner.

Repeating with Nix-built binaries on both sides gave a 1.3% wall-time difference;
standard deviations were 11.01 ms before and 11.53 ms after, about 1.5% each.
This does not establish a zero regression or explain the build-to-build
difference. The small Nix difference is close to observed run variation.
No codec optimization was made in response to these measurements. The initial
outliers and follow-ups remain in the log rather than being discarded.

## New Deflate Path

These measurements use the local ReleaseFast binary.

| Corpus | Iterations | Wall | CPU | Effective throughput |
| --- | ---: | ---: | ---: | ---: |
| Repeated text and x86 instructions, 360 KiB | 100 | 169.30 ms | 168.15 ms | 208 MiB/s |
| Uniform random, 1 MiB | 50 | 112.3 ms | 111.4 ms | 445 MiB/s |
| Gaussian bytes, 1 MiB | 50 | 493.58 ms | 489.99 ms | 101 MiB/s |

The raw decoder uses a 64 KiB stdlib history/output window plus its decoder
state; the sink adapter adds a 16 KiB output buffer. Archive tests verify the
360 KiB solid fixtures with each individual allocation capped at 96 KiB.
That is an individual-allocation check, not a 96 KiB total-memory cap. The range
adapter still retains compressed folder input. These measurements cover slice
verification; they do not quantify range-input or encrypted-archive performance.

## Reproduction and Provenance

Build each revision with `./build`, retaining its `z7z-verify-bench` executable
outside the checkout. Use the same build path for controlled comparisons.
`MUTE_DEBUG_STATUS` was unset. Production builds explicitly use ReleaseFast.

Payload recipes for the 360 KiB archives are in
[the fixture README](../../src/fixtures/deflate/README.md). The same two payloads
were archived with `7zz a -t7z -m0=LZMA2 -mmt=1` for the existing-path test.

The two 1 MiB corpora use the project's deterministic `tools/random` utility:

```bash
work=$(mktemp -d "${TMPDIR:-/dev/shm}/z7z-deflate-benchmark.XXXXXX")
nix develop -c tools/random --seed 271828 -b -c 1048576 > "$work/uniform.bin"
nix develop -c tools/random --seed 271828 -b -c 1048576 \
  --normalized --mean 128 --stddev 20 > "$work/gaussian.bin"
for corpus in uniform gaussian; do
  for method in LZMA2 Deflate; do
    nix develop -c 7zz a -t7z "-m0=$method" -mmt=1 \
      -mtc=off -mta=off -mtm=off "$work/$corpus-$method.7z" "$work/$corpus.bin"
    nix develop -c 7zz t "$work/$corpus-$method.7z"
    nix develop -c hyperfine --warmup 3 --runs 12 \
      --export-json "$work/$corpus-$method.json" \
      "zig-out/bin/z7z-verify-bench $work/$corpus-$method.7z 50"
  done
done
```

For paired comparisons, pass the retained baseline command as an additional
hyperfine command. The pinned controls prefix each command with `taskset -c 24`
and use 10 iterations. Archive creation and `7zz t` passed for every measured
fixture; the oracle was 7-Zip 26.00. No oracle source was inspected.
