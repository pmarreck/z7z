# Optional CRC Verification Measurements

Measured 2026-09-06 EDT on AMD Ryzen Threadripper 3990X, Linux x86_64,
Zig 0.16.0, ReleaseFast, using Nix builds on both sides. Baseline source is
075ecadc4200706d0c362afa699da47af83b31c9; the after binary contains the
archive/metadata CRC changes committed with this report, before codec integration.
Hyperfine used three warmups and twelve measured runs, each verifying a 1 MiB
archive fifty times. CPU means user plus system time. Fleet builds were active;
these measurements were not CPU-pinned.

| LZMA2 payload | Before wall | After wall | Before CPU | After CPU |
| --- | ---: | ---: | ---: | ---: |
| Gaussian bytes | 3768.67 ms | 3750.90 ms | 3745.09 ms | 3726.11 ms |
| Uniform bytes | 114.94 ms | 114.73 ms | 113.89 ms | 113.81 ms |

Wall differences are -0.47% and -0.18%. Standard deviations are 41.60/35.62 ms
for Gaussian and 1.33/0.91 ms for uniform. This does not establish a speedup;
no material regression was observed. These archives do not declare packed CRCs,
so this comparison measures the added dispatch check, not the cost of hashing
a compressed stream when its optional CRC is present.

The deterministic seed, payload hashes, archive sizes, and generation commands
are recorded in [the Deflate benchmark report](2026-09-04-deflate.md).
[Raw runs](2026-09-06-crc.json) retain both CPU and wall samples and commands.
The benchmark binaries were built with ./build; MUTE_DEBUG_STATUS was unset.
