# Optional CRC oracle audit

Observed 2026-09-06, 11:19-11:23 EDT with the supplied static 7-Zip 26.03 oracle.
Five small synthetic Copy archives reproduce the uncommitted parent helpers
`packedCrcFixture` and `encodedHeaderCrcFixture` in `src/archive.zig`.

## Results

| Fixture | `7zz t` | `7zz x -so` | Parent read / verify / verifyRange |
| --- | --- | --- | --- |
| `packed-good.7z` | 0 | 0, exact payload | Accept |
| `packed-bad.7z` | 0 | 0, exact payload | `ChecksumError` |
| `encoded-good.7z` | 0 | 0, exact payload | Accept |
| `encoded-bad-pack.7z` | 0 | 0, exact payload | `ChecksumError` |
| `encoded-bad-folder.7z` | 2, `Headers Error` | 2, no payload | `ChecksumError` |

7zz 26.03 did not enforce the ordinary packed CRC or the encoded-header packed
CRC in these Copy fixtures. Its successful integrity test printed
`Everything is Ok`. The encoded-folder CRC mismatch was rejected while opening
the archive. Both good counterparts were accepted and extracted exactly 18 bytes.

The parent's checks are stricter than the oracle for these two packed-CRC
cases. Their correctness claim must rest on explicit CRC validation and the
format requirement, rather than an assertion that 7zz rejects the same files.
This audit does not establish oracle behavior for other compression methods.

## Fixtures And Provenance

All files are in `src/fixtures/crc/`; none contains private archive data.

- `packed-good.7z` and `packed-bad.7z` contain `crc.txt`, whose expected bytes
  are in `packed.txt`: `packed CRC fixture` (18 bytes, no newline).
- `encoded-good.7z`, `encoded-bad-pack.7z`, and `encoded-bad-folder.7z` contain
  `header.txt`, whose expected bytes are in `header.txt`: `header CRC fixture`
  (18 bytes, no newline).
- `provenance.json` records construction flags, executable and file SHA-256
  hashes, exact oracle commands, exit statuses, captured stdout/stderr, parent
  source/test hashes, and the parent revision at the observation checkpoint.

The fixtures were generated using exact local copies of the two parent helper
bodies, with only the `archive.createWithMethod` namespace qualifier added.
No parent helper was exported or moved. The bad variants XOR one CRC bit with
`1`; start-header and next-header CRCs are recomputed. Independent Node zlib
checks confirmed both outer CRCs, and byte comparison confirmed exactly one
changed byte outside the 32-byte signature, located in the next header. Packed
payloads and decoded header bytes remain unchanged.

## Verification

The initial two good-counterpart tests failed with exit 2 before the fixture
helpers were implemented. After reproduction, both passed. Bad-CRC decisions
were first observed without assuming rejection, then encoded as assertions.
Final scratch result: 5 tests passed, 0 failed, no skips.

The parent API check covered all five archives through retained extraction,
slice verification, and range verification with borrowing disabled. Both good
cases reported 18 unpacked bytes; all three bad cases returned `ChecksumError`.
This does not cover the C CLI or the complete project suite.

Focused command used while the scratch test was at the module root:

```bash
nix develop /home/pmarreck/Code/z7z -c zig test src/crc_oracle_test.zig -O ReleaseSafe -target x86_64-linux-musl -lc --test-filter crc-oracle
```

The scratch test is retained recoverably at
`/dev/shm/z7z-crc-oracle-20260906/crc_oracle_test.zig`; its relative imports need
the `src` module context to rerun. It is excluded from the repository, avoiding
duplicate helper implementations and a committed hardcoded oracle dependency.
Parent tests can embed these archived bytes and expected payloads directly.

To repeat a black-box observation with a compatible oracle available locally:

```bash
"$ORACLE" t src/fixtures/crc/encoded-bad-folder.7z
"$ORACLE" x -so src/fixtures/crc/packed-bad.7z
```

The first command is expected to return 2; the second returns 0 and emits the
18-byte packed payload under 26.03. No extracted content was executed, no
original 7-Zip implementation source was inspected, and no private archive data was published.
